# Журнал

Автоматический дневник действий по проекту. Заполняется ботом
`.github/workflows/journal.yml` раз в сутки (00:10 UTC) на основе git-коммитов.

## Что внутри

- `YYYY-MM-DD.md` — два файла: за **сегодня** и **вчера** (UTC).
- Всё, что старше вчера, бот удаляет при следующем запуске.
- Внутри файла коммиты разделены на **«Изменения от команды»** и
  **«Изменения от Claude»** (определяется по маркеру
  `claude.ai/code/session_` в теле коммита).
- Источник — git log на ветке `main`, поэтому изменения от Claude
  попадают в журнал только **после мержа** соответствующей ветки в `main`.

## Запустить вручную

GitHub → Actions → **Daily Journal** → **Run workflow**.
